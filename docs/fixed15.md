# Задание 2: умножение чисел с фиксированной точкой

## Формат

По согласованному варианту операнды знаковые, результат полный, без сокращения
разрядности. Код всех чисел дополнительный.

| Параметр | Входы A, B | Выход Y |
| --- | --- | --- |
| Полная разрядность | 15 | 30 |
| Дробные разряды | 5 | 10 |
| Знаковый разряд | 14 | 29 |
| Значение | signed15(код) / 32 | signed30(код) / 1024 |

Входной диапазон: −512…511,96875 с шагом 1/32. Отдельного порядка нет.
Если целые коды входов равны a и b, то выходной код y = a · b.
Следовательно, Y = y / 1024 = (a / 32) · (b / 32).
Все дробные разряды произведения сохраняются: округление не требуется.

## Обоснование вентильной схемы

Каждый вход представлен суммой положительных разрядов 0…13 и отрицательного
знакового разряда 14. В произведении формируются 225 частичных произведений
Ai AND Bj с весом 2^(i+j).

Термы, содержащие ровно один знаковый разряд, имеют отрицательный вес.
Таких термов 28. Они инвертируются вентилями NOT, а к сумме добавляется
поправка 2^15 + 2^29. Это форма умножения Боуга–Вули в дополнительном коде.
Знаковый терм A14 AND B14 имеет положительный вес и не инвертируется.

Поправка следует из равенства −t = (1 − t) − 1 для одного бита.
Суммарный вес инвертируемых позиций:

```text
2 · 2^14 · (2^14 − 1) = 2^29 − 2^15
```

Поэтому после инверсии нужно вычесть 2^29 − 2^15. По модулю 2^30 это
равносильно добавлению 2^29 + 2^15. Единица получена через A0 OR NOT A0;
она заведена на свободные позиции первой строки частичных произведений.
Таким образом, не нужны отдельные высокоуровневые блоки коррекции или MUL.

Строки суммируются полусумматорами и полными сумматорами, раскрытыми до вентилей:

```text
Полусумматор: S = A XOR B, C = A AND B.
Полный сумматор:
P = A XOR B
S = P XOR Cin
Cout = (A AND B) OR (P AND Cin)
```

Итоговый 30-битный код интерпретируется как знаковый. Для допустимых входов
целое произведение лежит в диапазоне −268419072…268435456, который полностью
помещается в 30-битный дополнительный код. Выходной флаг переполнения не нужен.
Отбрасывание переноса за разряд 29 является частью модульного представления,
а не потерей значимых разрядов произведения.

Примеры: 1,5 · (−2,25) = −3,375; (1/32) · (1/32) = 1/1024;
(−512) · (−512) = 262144.

## Триггеры

Входы: RA00…RA14 и RB00…RB14. Выходы: RY00…RY29.
Дополнительные RSYNC и YSYNC передают бит валидности. Всего 62 D-триггера
с общим тактовым сигналом CLK. Данные захватываются на фронте n,
результат и SYNC_OUT появляются на фронте n+1. SYNC не входит в числовое слово.

Нулевой SYNC обозначает невалидное слово, не остановку тактирования.
Сброс не предусмотрен; до первого SYNC_OUT=1 выход игнорируется.
Период CLK должен учитывать задержку всей комбинационной цепи и параметры
реальных триггеров. Программные тесты проверяют логику, не физический тайминг.

## Отдельные файлы

Первое задание находится в `output/assignment15`, второе в `output/fixed15`.
Генераторы и YAML независимы. Общими являются только инструменты рисования,
размещения, трассировки и базовый построитель вентилей.

Генерация второго задания с нуля:

```powershell
python -m schematic_renderer.fixed15
```

Она создаёт `fixed15.logic.yaml` с полной логикой, `fixed15.yaml` с координатами
и маршрутами, а также `fixed15.png` и `fixed15.svg`. Блоки остаются крупными:
шрифты 24/20 px, минимальный размер блока 180 × 104 px. Холст растёт по схеме.
Точка обозначает соединение, дуга — пересечение проводов без контакта.

Перерендерить оба задания без повторной компоновки:

```powershell
python -m schematic_renderer output/assignment15/assignment15.yaml -o output/assignment15/assignment15.compact.png
python -m schematic_renderer output/fixed15/fixed15.yaml -o output/fixed15/fixed15.png
```

Для SVG укажите расширение `.svg` вместо `.png`. При перерендере готового YAML
Node.js не требуется. Если просмотрщик блокирует перезапись картинки, укажите
другое имя выходного файла либо закройте её в просмотрщике.

После изменения логических соединений размещение второго задания пересчитывается
отдельно:

```powershell
python -m schematic_renderer.prepare output/fixed15/fixed15.logic.yaml -o output/fixed15/fixed15.yaml
```

Первое задание генерируется командой `python -m schematic_renderer.assignment15`.
Она никак не затрагивает каталог `output/fixed15`, и наоборот.

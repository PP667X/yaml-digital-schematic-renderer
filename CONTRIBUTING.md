# Разработка и публикация

## Окружение

```powershell
python install.py --dev --layout
.venv\Scripts\python.exe -m pytest -q
```

Тесты проходят с пустым `output`: постоянные схемы находятся в `examples`,
временные изображения создаются в каталогах pytest.

```text
schematic_renderer/  парсер, размещение, трассировка, PNG/SVG, CLI
examples/            небольшие примеры и две функциональные схемы
docs/                установка, YAML, обоснование учебных схем
tests/               формат, геометрия, арифметика, установщик
output/              результаты; Git хранит только .gitkeep
install.py           локальная установка в .venv
.github/workflows/   CI: установка, тесты, рендер, сборка
```

Для изменения рисунка редактируйте YAML. Для дефектов геометрии добавляйте
регрессионный тест и проверяйте PNG визуально. Интерфейс рисования используется
Pillow и SVG, поэтому проверяйте оба формата. Код должен поддерживать Python 3.10.
Арифметические контракты YAML не исполняются рендерером: для них нужны отдельные
поведенческие тесты.

## Сборка

```powershell
.venv\Scripts\python.exe -m pip install build
.venv\Scripts\python.exe -m build
```

`dist` содержит wheel и исходный архив. Исходный архив включает документацию,
примеры, установщик и npm lockfile. Wheel содержит Python-модули и `.cjs`, но
не содержит `node_modules`. Для ELK рекомендуется установка из клона или
исходного архива через `install.py --layout`.

## GitHub

Подготовка проекта не публикует файлы автоматически. Создайте пустой репозиторий
в своём аккаунте, затем выполните из корня проекта:

```powershell
git init
git add .
git status
git diff --cached --stat
git commit -m "Initial release"
git branch -M main
git remote add origin <URL-вашего-репозитория>
git push -u origin main
```

Перед коммитом проверьте, что не добавлены секреты и личные файлы. Если Git или
remote уже настроены, не повторяйте их создание. При необходимости задайте
свои `user.name` и `user.email`: проект не меняет эти личные настройки.

CI запускается на push/pull request и вручную, проверяет Windows с Python 3.10
и 3.12. После первого push проверьте вкладку Actions: локальные тесты не являются
подтверждением удалённого CI.

Не коммитьте `.venv`, `node_modules`, `output`, кэши и личные `.env`-файлы.
